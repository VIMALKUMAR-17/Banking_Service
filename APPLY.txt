HOW TO APPLY (Windows, from your project root - the folder containing manage.py)

1. Commit or stash any uncommitted work first.
2. Extract this zip over the project root, allowing it to overwrite files.
   (Only Accounts/templates/*.html and Accounts/static/* are touched.)
3. DELETE these four files - they are unused/superseded (nothing references them):
     Accounts\static\all-responsive.css
     Accounts\static\home.css
     Accounts\static\login.css
     Accounts\static\register.css
   PowerShell:
     Remove-Item Accounts\static\all-responsive.css, Accounts\static\home.css, Accounts\static\login.css, Accounts\static\register.css
4. Run:  python manage.py runserver
   (If you deploy with WhiteNoise/collectstatic, build.sh already runs collectstatic.)
5. Hard-refresh the browser (Ctrl+F5) so old CSS is not cached.

No Python, models, migrations, URLs or settings were changed. Nothing was committed or pushed.

Optional: ui_tests/ contains the regression scripts used to verify this work
(requires: pip install django djangorestframework django-cors-headers whitenoise requests playwright).
